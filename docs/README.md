# توثيق مشروع منصة مكي للمحاماة — دليل سريع

هذا المجلد هو مصدر الحقيقة الوحيد لقرارات وتاريخ المشروع (متزامن مع نفس
المحتوى المحفوظ في Claude Project "mekky law"). لو بتفتح المشروع من جديد
(محادثة تانية، أداة ذكاء اصطناعي تانية، أو مطوّر تاني)، ابدأ من هنا.

## إيه المشروع

منصة "مكي للمحاماة": موقع تعريفي + منصة تعليمية (LMS) بمسارين (كورسات لطلاب
حقوق، ودورات لمحامين متخرجين). التفاصيل الكاملة في `prd.md`.

## الحالة الحالية (آخر تحديث: 3 سبتمبر 2026)

- **Phase 0 (التأسيس التقني):** ✅ مكتملة ومُختبَرة.
- **Phase 1 (نواة الـ LMS):** ✅ مكتملة ومُختبَرة حيًّا بالكامل — مدرب أنشأ
  كورس (قسم + درس فيديو حقيقي + امتحان)، طالب اتفعّل اشتراكه، شاهد الفيديو،
  حل الامتحان، كل حاجة نجحت. **إضافة بعد الأساس:** فيتشر أسئلة داخل الفيديو
  (Video Checkpoints) — راجع `sprints/sprint-video-checkpoints.md`. ✅ مُختبَر حيًّا.
- **Phase 2 (الدفع):** الكود مبني بالكامل (`payments` module + Kashier
  provider) ومُتحقق منه بالاختبارات، **لكن لسه محتاج حساب Kashier Sandbox
  حقيقي من العميل** عشان نختبر الفلو الفعلي كامل (checkout → دفع → webhook).
  راجع `sprints/sprint-payments.md`.
- **Phase 3 (الموقع التعريفي + الاستشارات) و Phase 4 (التحسين والإطلاق):**
  لسه ماتبدأش.

### باقي معلّق (Open Items) وقت كتابة السطور دي

1. **حساب Kashier Sandbox حقيقي** (`KASHIER_MERCHANT_ID`/`KASHIER_API_KEY` في `.env`) — مطلوب من العميل، مذكور في `sprints/sprint-payments.md`.
2. **شهادة الطالب (Certificate)** — الامتحان اتجرّب حيًّا ونجح، لكن إصدار الشهادة نفسها (PDF بعد اجتياز الامتحان) لسه محتاج تأكيد اختبار حي منفصل.
3. **درس فيه ملف مرفوع غلط** — أثناء اختبار الرفع، درس واحد اترفعله صورة بالغلط بدل فيديو (اسمها بيبدأ بـ "بيرفع...") — محتاج إعادة رفع بالفيديو الصح من لوحة الأدمن.
4. **ريفاكتوري وفحص شامل للمشروع كله** (Phase 0+1+2) — لسه ماتبدأش.
5. **بحث عام في أفضل ممارسات LMS (معيار Coursera)** وتحديد فيتشرز ناقصة تستاهل تتضاف — لسه ماتبدأش.

## إزاي تشغّل المشروع محليًا

راجع `setup-local.md` للخطوات الكاملة. ملخّص سريع: 3 عمليات لازم تكون شغالة
مع بعض (API، Worker التحويل، الفرونت إند)، وDocker لـ Redis (طابور
التحويل) — لازم يكون Redis على البورت اللي متسجّل في `REDIS_URL` بالظبط
(مش مشترك مع مشروع تاني على بورت مختلف).
